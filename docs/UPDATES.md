Ошибка сохраняет прежнее предложение максимум на семь суток, затем скрывает его. Ошибки не мешают статистике.

Манифест: фиксированный `https://dsf.finance/downloads/android/latest.json`, schemaVersion=1, applicationId=finance.dsf.widget, положительные целые versionCode/minSdk, versionName из цифр с точками, apkUrl строго `https://dsf.finance/downloads/DSF-Finance-Widget-{versionName}.apk`, sha256 — 64 hex. Новизна только по versionCode, совместимость по minSdk. Строковые/дробные числовые поля и чужие адреса отклоняются. HTTPS без редиректов, timeout 8 секунд connect/read, общий лимит чтения 20 секунд и 16 KiB ответа. Внешние данные не задают произвольные команды, Intent или HTML.

Кнопка открывает проверенный HTTPS URL в браузере по явному нажатию; APK не скачивается фоном и не устанавливается приложением. Разрешение REQUEST_INSTALL_PACKAGES не нужно. SHA256 публикуется для контроля раздачи, приложение не заявляет проверку скачанного браузером файла; установку и подпись проверяет Android. Секретов/идентификаторов кошелька в запросе нет. Нет уведомлений, фоновой проверки версии, Google Play, кошельков, изменений финансовых данных или API.
