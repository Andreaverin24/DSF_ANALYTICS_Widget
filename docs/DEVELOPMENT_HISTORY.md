## Данные

| Показатель | Источник | Поле |
|---|---|---|
| APY | [DeFiLlama chart, выбранный владельцем](https://yields.llama.fi/chart/774082cb-0775-4718-bac0-fde0165c8f9c) | `data[].apy` |
| TVL | DSF Watchdog `https://watchdog.dsf.finance/proxy/apy` | верхнее числовое `tvl` |

`MarketHistory.java` сохраняет все точки APY последних 30 дней с исходными отметками времени; последняя APY отображается сверху. Текущий TVL читается отдельно из `/proxy/apy`; его история не нужна для отключённого графика. `tvlUsd` DeFiLlama и ставки из `/proxy/apy` не используются. Никакой формулы APY, стратегии или DSF LP Price в APK нет.

Нули и отрицательные APY остаются значениями; отсутствующие числа остаются null. Сглаживание относится только к линии. Ошибка одного API сохраняет его предыдущие данные и не блокирует второй. Виджет отмечает несвежие данные, сохраняя числа, если последний успешный ответ TVL получен более 2 часов назад либо исходная отметка APY старше 48 часов. `/proxy/apy` не сообщает дату расчёта TVL: `tvlAsOf` — время получения ответа, оно не доказывает свежесть серверного расчёта.

Первая загрузка запускается при добавлении виджета; далее обновление примерно раз в 30 минут с ограничениями Android. Открывать приложение не требуется. Открытие приложения дополнительно запускает обновление отсутствующих/ошибочных данных или кэша старше 30 минут. Оба задания JobScheduler сохраняются после перезагрузки; receiver восстанавливает расписание после boot/update APK. Ошибка/прерывание повторяется с системным экспоненциальным backoff от минуты. Последний удалённый виджет отменяет задания. JSON-кэш атомарный, схема 4 маркирует новый источник TVL; из точной схемы 3 разрешён перенос только прежнего DeFiLlama APY. Отменённая работа не сохраняется и не завершает новый запуск. HTTPS, timeout, лимит ответа 16MiB. Секретов/кошелька/транзакций нет. API, Watchdog, Analytics и БД не менялись.

## Сборка

JDK17+, Android SDK36, Gradle Wrapper9.4.1, AGP9.2.1. Указать SDK в `local.properties`. Node/TypeScript и JavaScriptEngine больше не используются.

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

Проверка на телефоне без удаления приложения:

```powershell
adb -s DEVICE install -r app/build/outputs/apk/debug/app-debug.apk
adb -s DEVICE install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s DEVICE shell am instrument -w finance.dsf.widget.test/androidx.test.runner.AndroidJUnitRunner
```
