# DSF Finance — Android Analytics Widget

**Version 0.3.9 · Android 8.0+ · Java / RemoteViews / Canvas**

[Скачать APK с dsf.finance](https://dsf.finance/downloads/DSF-Finance-Widget-0.3.9.apk) · [SHA-256](releases/SHA256SUMS.txt) · [Манифест обновлений](https://dsf.finance/downloads/android/latest.json)

Виджет показывает TVL, текущую APY и сглаженный график APY за 30 дней. Значения обновляются автоматически примерно раз в 30 минут с учётом ограничений Android. Шрифт Roboto встроен, изменения цифр анимированы. Номер установленной версии отображается внизу графика.

В приложении: средняя APY за 30 дней, текущая APY и TVL, кнопки добавления виджета и открытия сайта. При открытии приложение проверяет новую версию APK не чаще раза в сутки. Если доступен совместимый новый релиз, появляется «Скачать обновление». Скачивание открывается в браузере по нажатию; установку подтверждает пользователь через Android. Нет автоматической установки и фонового скачивания APK.

## Источники данных

| Показатель | Источник |
|---|---|
| TVL | `https://watchdog.dsf.finance/proxy/apy`, верхнее числовое поле `tvl` |
| APY, график, средняя ставка | `https://yields.llama.fi/chart/774082cb-0775-4718-bac0-fde0165c8f9c`, `data[].apy` |

APY не вычисляется из стратегий. Нули и отрицательные APY сохраняются. Средняя APY — среднее доступных годовых ставок за 30 дней, не фактическая доходность за месяц. График TVL отключён. Ошибка одного источника сохраняет его предыдущие данные и не блокирует другой. При устаревании данных виджет показывает соответствующую подпись. API TVL не сообщает дату расчёта: сохраняется время получения ответа.

Приложение не подключает кошелёк, не подписывает транзакции и не хранит ключи пользователя. Только HTTPS; проверка обновлений допускает APK из фиксированного каталога dsf.finance. Подробный контракт: [docs/UPDATES.md](docs/UPDATES.md).

## Установка

Скачайте APK, установите его и откройте **DSF Analytics** → **Добавить виджет**. Виджет также доступен через меню домашнего экрана Android. Размер меняется удержанием, нажатие открывает приложение.

Первый публичный APK подписан постоянным release-ключом. Последующие версии устанавливаются поверх него с сохранением данных. Старые внутренние debug-сборки используют другую подпись; поверх них публичный release не устанавливается. Не удаляйте тестовую установку автоматически при проверках.

## Разработка и сборка

JDK из Android Studio, Android SDK 36, Gradle Wrapper 9.4.1 / AGP 9.2.1, Java source level 17. Укажите Android SDK в локальном `local.properties`. Файл не входит в Git.

```powershell
.\gradlew.bat :app:assembleDebug :app:lintDebug :app:testDebugUnitTest
```

Публичный релиз собирается владельцем постоянного ключа:

```powershell
.\scripts\Build-Release.ps1
```

[SIGNING.md](SIGNING.md) описывает подпись и резервные копии. Keystore, пароли, локальные конфигурации и снимки телефона исключены из Git. APK распространяется через сайт; в репозитории находятся исходники и контрольная сумма релиза.
